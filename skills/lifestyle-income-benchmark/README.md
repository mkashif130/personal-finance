# Lifestyle & Income Benchmark Skill

A ready-to-use, privacy-conscious AI skill that interviews a household about income, housing, vehicles, schooling, benefits, leisure, dependents and spending; benchmarks peers using properly comparable data; and recommends optional high-value lifestyle adjustments.

## Installation / use
- For agent frameworks that accept `SKILL.md`, put this folder in the framework's skills directory.
- For ChatGPT or another chat interface without custom skill file ingestion, paste the content of `SKILL.md` into the instructions for a custom assistant/project.
- The skill describes research expectations; current market prices and percentile rankings require web/data access.

## Files
- `SKILL.md`: primary skill instructions.
- `INTAKE_TEMPLATE.md`: optional structured intake worksheet.
